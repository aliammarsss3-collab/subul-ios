# سُبُل

تطبيق iPhone عربي بسيط للمراسلة والاتصال بين حسابين شخصيين ثابتين. بيانات الدخول لا تُنشر كنص داخل المستودع.

## استخراج IPA غير موقّع

افتح تبويب **Actions** في GitHub، ثم افتح **Build unsigned IPA** واضغط **Run workflow**.
بعد اكتمال البناء نزّل الملف من قسم **Artifacts** باسم `Subul-unsigned-IPA`.

## تنبيه مهم

هذه نسخة شخصية تجريبية. الرسائل تنتقل عبر موضوع عام غير مشفّر تشفيراً طرفياً، والاتصال يفتح غرفة Jitsi في المتصفح. لا تستخدمها لإرسال معلومات خاصة أو حساسة، ولا تنشرها كتطبيق عام قبل إضافة مصادقة وخادم خاصين.
